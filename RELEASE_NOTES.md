## Bug Fixes

- **Members-only scans and live chat work on YouTube's new page layout.** YouTube has begun serving some signed-in pages with the page data Moombox reads (`ytInitialData`) in a JSON script element of its own instead of a script assignment. On those pages the members-only tab scan found nothing and live-chat capture lost its continuation, both without an error. Moombox now reads the new element too, as yt-dlp does.
- **Security updates.** Moombox is now built with Go 1.27.3, which stops trusting a set of compromised intermediate certificates (GO-2026-6809), and golang.org/x/net 0.62.0, which closes two HTML parser advisories (GO-2026-6860, GO-2026-6866). The Node runtime embedded for the BotGuard sidecar moves to v24.22.2 (undici 7.30.1, OpenSSL 3.5.9), for the undici advisories and Node's October security release: the sidecar's requests run on the undici copy built into Node, which `npm audit` cannot see.
- **Chat files on Windows survive a virus scanner's brief hold.** Saving chat messages that could not be flushed to a `.lostbatch.json` spill, and setting an unreadable chat file aside, used a plain rename, which Windows refuses while a scanner still holds the file. The second spill of a part, moments after the first, then failed and reported its messages unsaved, and a refused set-aside let the next write overwrite the bytes it meant to keep. Both now retry, as every other chat write already did.

## Internal

- **Dependencies.** go-chi/chi 5.5.0, modernc.org/sqlite 1.61.0 (libc 1.79.0), golang.org/x/net 0.62.0, and jsdom 30.1.3 in the BotGuard sidecar and the web test harness. The toolchain floor is go1.27.3 and the embedded Node is v24.22.2.
- **CI answers in about three minutes.** It runs as 13 parallel jobs (lint, the JavaScript suites, and the Go suite split by package into shards for linux, race and windows) instead of one serial job per OS, so a push gets its result in about three minutes instead of nine to thirteen. Every installer and download in CI and in the release job is retried under a time limit; an apt mirror once hung a run for 22 minutes.
- **The flaky tests are fixed.** Every irregular failure in the CI history was traced to its cause, and the tests of the same shapes across the suite were fixed with it. Tests that bounded wall-clock time over disk or network work now count what happened, tests that read a result before its worker had cleaned up now wait for the cleanup, and background work that outlived a test's temporary folder is joined or switched off. The out-of-memory crash test no longer exhausts a Windows runner's memory, which was behind the "paging file is too small" failures in v2.9.6's tag runs. The slowest packages' tests run at test scale, and tests another one already covers were merged into it.
- **The README thanks the projects Moombox is built on.** It now opens with them, and with what it learned from each.
- **Upstream review ledger.** `docs/spec/upstream-ports.md` records where the last review of yt-dlp, ejs and BgUtils left off, and what is still open.
