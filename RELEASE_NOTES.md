### Internal

- **CI: simpler sequential builds with per-binary named steps.** Reverted the 3-way parallel cross-compilation introduced in 2.6.6 — measurement showed it only saved ~8s on a 4-vCPU runner (each `go build` was already CPU-saturating alone, so concurrent builds just contended for cores) and had introduced two latent bugs (parallel sign's bare `wait` silently swallowed exit codes; parallel build raced on module cache and re-downloaded every dep three times). Sequential builds + signs are simpler, give cleaner per-binary logs, and the first build naturally warms the module cache for the next two — no separate pre-download step needed. Each cross-compile and signing operation now lives in its own named step so the GitHub Actions UI shows per-binary timing and failure attribution.
