### Bug Fixes

- **Windows: deferred cleanup of `Moombox.exe~` orphans now actually fires.** The 2.6.5 launcher restructure replaced the historical `ping`-based delay with `timeout /t 11 /nobreak`, which per Microsoft's documentation errors out unconditionally when stdin is redirected — and the cmd subprocess Moombox spawns always has stdin redirected. The `del` then ran instantly, before the launcher had released the file lock, and silently failed. The orphan stayed until the next launch where the startup-time cleanup at `launcher.go:50` would catch it. Now uses `ping 127.0.0.1 -n 5` (5 pings × 1s = ~4s of wall-clock delay) which has no stdin dependency. Cleanup happens within seconds of clean exit instead of waiting for the next launch.
