## Internal

- **Dependencies.** `charm.land/bubbletea/v2` 2.0.10 (the TUI framework), `github.com/ulikunitz/xz` 0.5.17 (used only by the Node-fetch build tool), and jsdom 30.1.1 inside the BotGuard sidecar; each gated by the full suite, the TUI frame-cost check, the sidecar's own 30-test suite and the live sidecar check, and the three platform builds.
- **Two test assumptions that only held on the developer's machine.** v2.8.9 was the first push since v2.8.8, so GitHub's runners exercised those tests for the first time and two failed on host details rather than behaviour: the folder-open test compared a resolved program name verbatim while the Windows runner carries an `open.exe` on its PATH, and the probe-drain test's byte cap was measured on Windows loopback where Linux buffers several times more. Both tests now assert the same behaviour with host-independent margins; no production code changed.
