### Improvements

- **"COOKIES?" status renamed to "Auth Required"** — clearer label for new users when YouTube/Twitch authentication expires
- **Progress tooltips explain abbreviations** — hovering over compact progress text (V/A/C segment counts) now shows a human-readable description (e.g. "Audio: 123/456 segments, Video: 789 segments, Chat: 50 messages")
- **Filter empty state improved** — "No matching jobs" now tells users that search matches titles and channel names
- **Status bar compacted on mobile** — timers stack vertically, padding reduced, icon buttons shrunk, version indicator hidden (available in Settings)
- **Warning text collapsed to icon on mobile** — re-login warnings show as a single warning triangle icon instead of full text
- **Theme toggle removed from status bar** — will return as part of a future theming system
