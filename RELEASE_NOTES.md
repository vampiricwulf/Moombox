### Bug Fixes

- **Launcher: `.exe~` orphan from updates now actually gets cleaned up on exit.** The deferred `cmd /C ping ... & del` was being mangled by Go's CRT-style argument escaping when the whole command was passed as a single string — Go quotes the combined string and escapes embedded `"` as `\"`, which cmd.exe doesn't understand (cmd uses `""` for embedded quotes). `del` received a mangled path and `>nul 2>nul` swallowed the failure. Reverted to v2.5.2's variadic-args form where each token (`>nul`, `&`, path) goes through Go's escaper independently and cmd parses them correctly. Startup `cleanupOrphans` was masking the regression — orphans got removed eventually, just one launch later than intended.
