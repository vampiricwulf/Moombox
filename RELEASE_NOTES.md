## Bug Fixes

- **Quality probe now supports manifestless DASH streams.** The 30-second quality monitor was bailing with `quality probe error (skipping) err="no DASH manifest URL"` for streams hit by the YouTube account experiment, because it expected `info.DashManifestURL` to be populated. Add a parallel branch: when DashManifestURL is empty and `HasManifestlessDashFormats(info.Formats)` is true, derive the quality from `info.Formats[]` directly using the same `SelectBestDashStream` selector. No manifest fetch needed — pure in-memory pass.
- **Quality probe nil-guard.** The probe dereferenced `info.DashManifestURL` without checking `info != nil`. During a context-cancel shutdown race, the YouTube service can return `(nil, nil)` when every Innertube client fails before producing either a parsed result or a hard error. The deref panicked the quality monitor goroutine — caught by the existing recover() but the monitor exited for the duration of the download. Treat nil-without-error as a transient probe error so the monitor keeps running.
