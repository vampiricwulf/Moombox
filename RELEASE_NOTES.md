### Features

- **App icon** — Moombox.exe now has an embedded application icon and Windows version info (visible in Explorer and Properties → Details)
- **Reference update script** — `references/update-all.sh` auto-clones missing upstream repos and shows Moombox-relevant changes when updating

### Improvements

- **CI version injection** — Windows resource version and commit hash are now generated from the git tag at build time, no manual syncing needed
- **README** — Added documentation for auto-updater, quality monitoring, statistics dashboard, mobile responsive support, and multi-segment playback
- **CLAUDE.md** — Expanded as transferable working memory with design constraints, key dependencies, reference update workflow, and self-maintenance process
